# GitHub Contributions

The contribution history of a GitHub user over a selected date range.

## Language

**Daily contribution count**: The number of contributions GitHub attributes to a user on one calendar date.

**Contribution window**: The consecutive calendar dates included in the requested contribution history. This project's window contains 112 days, including the current day in UTC.

**Contribution snapshot**: The daily contribution counts returned by one successful retrieval for a contribution window.

**Contribution updater**: The device's background activity that periodically obtains a new contribution snapshot for its local display.

**Stale snapshot**: A contribution snapshot whose current accuracy has not been confirmed within the agreed freshness period. It remains available for display while the contribution updater cannot obtain a fresh snapshot.
